# Flip-Flop and Counter Design

## Project Overview

This project explores sequential logic circuits using Logisim Evolution.
It includes flip-flop design and a 4-bit synchronous binary up-counter.

## Objectives

- Understand sequential logic.
- Study D, JK, and T flip-flops.
- Observe clock-triggered state changes.
- Design a 4-bit binary counter.
- Verify the counter's counting sequence.

## Tools Used

- Logisim Evolution
- Git
- GitHub

## Circuits Implemented

- D Flip-Flop
- JK Flip-Flop
- T Flip-Flop
- 4-bit Binary Counter

## Counter Operation

The counter progresses through binary states from 0000 to 1111,
then returns to 0000.

## Applications

- Digital clocks
- Event counters
- Frequency division
- Digital control systems
- Embedded systems
